Reading paths

Not sure where to start? Pick the goal that fits. Each path lists the pages in the order they build on one another:

  • Just run it. Tutorial -> User Guide -> Runbook.
  • Understand the algorithms. Explainer -> GSK -> the variant guides (AGSK, APGSK, FDB-AGSK, ATMALS-GSK, EGSK) -> DT-GSK (the proposed method) -> Numerical Examples.
  • Reproduce or validate results. Researcher Handbook -> Reproducibility -> Validation Report -> the CEC C++/Python equivalence reviews under Reference.
  • Compare algorithms statistically. Statistical Analysis -> Benchmark Protocol -> Result Schema.
  • Contribute code. Code Reading Guide -> Developer Guide -> Extension Guide -> Contributor Guide.
  • Look something up. Configuration, API Reference, Result Schema, Glossary, Diagrams.
The seven runnable optimizers are gsk, agsk, apgsk, fdb-agsk,
atmals-gsk, egsk, and dt-gsk. The benchmark registry supports six
suites -- the sphere suite plus five CEC suites (cec2011, cec2013,
cec2013lsgo, cec2017, cec2020) -- of which three (cec2011, cec2013,
cec2017) carry committed reference evidence. egsk is also a committed
reference comparator, and the statistical panel reports its cells from that
reference data.

Algorithm Guides - algorithms/

One guide per runnable optimizer, in increasing order of elaboration over the base gaining-sharing-knowledge scaffold:

  • GSK: the base gaining-sharing-knowledge algorithm.
  • AGSK: adaptive parameter pools over GSK.
  • APGSK: adaptive parameters tuned for engineering optimization.
  • FDB-AGSK: AGSK with the fitness-distance-balance guiding mechanism.
  • ATMALS-GSK: auto-tuning memory-based adaptive local search GSK.
  • EGSK: enhanced GSK -- dual adaptive knowledge factors, a fixed senior partition, and interior-point refinement (runnable MATLAB port; also a reference comparator).
  • DT-GSK: this project's proposed method -- Dimension-Tiered Gaining-Sharing Knowledge, adding a dimension-aware interaction-structure memory to the scaffold.

Development - development/

Living guides (see the folder index):

  • Developer Guide: day-to-day development guide.
  • Contributor Guide: contribution rules.
  • Maintenance Guide: routine upkeep.
  • Extension Guide: adding an optimizer, suite, artifact, or CLI.
  • Code Reading Guide: how to inspect the codebase.

  • EGSK Port Spec: porting analysis and decision record for the EGSK MATLAB port (the algorithm guide is EGSK).
