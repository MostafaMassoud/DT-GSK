configure_numba_runtime

configure_numba_runtime(*, suite: str, parallel: bool, workers: int, requested_threads: int = 0) -> dict[str, Any]

Configure and report Numba runtime state for benchmark execution.

The runner parallelizes independent runs with Python workers (processes by default, threads only for diagnostics). Many benchmark kernels also use Numba ``prange`` internally. Letting every external worker use the full Numba thread pool can oversubscribe the CPU badly, so auto mode caps Numba threads to roughly ``logical_cores / workers`` when external parallelism is enabled.
