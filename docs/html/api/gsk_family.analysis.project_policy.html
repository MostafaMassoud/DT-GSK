gsk_family.analysis.project_policy

Source: src/gsk_family/analysis/project_policy.py

Project-level optimizer and comparator policy for the analysis layer.

Dependency-free single source of truth for the GSK-family optimizer ids and the reference-comparator panel consumed by the statistical-analysis modules. Vendored and adapted from the source DT-GSK project; ``RUNNABLE_OPTIMIZERS`` reflects this project's seven locally executable optimizers.
