peek_doubles

peek_doubles(self, count: int) -> np.ndarray | None

Expose the next ``count`` uniforms without consuming them (or None).

Additive helper for the vendored external baselines (``optimizers/external``), whose ``NormalStream`` vectorizes a rejection loop while consuming exactly as many uniforms as the scalar path would, keeping results bit-identical. Returns ``None`` on generators without look-ahead so callers keep a scalar fallback. No family optimizer calls this; behaviour of every existing draw path is unchanged.
