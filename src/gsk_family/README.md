# gsk_family Package

`gsk_family` is the importable Python runtime for the GSK family.

## Areas

| Path | Purpose |
|---|---|
| `analysis/` | Post-run result comparison and plotting helpers. |
| `benchmark_adapter/` | Suite protocol metadata and problem construction. |
| `cli/` | Console script entry points. |
| `common/` | reference-compatible shared helpers. |
| `optimizers/` | Optimizer kernels. |
| `runners/` | Experiment config, execution, output, parallelism, profiling, and verification. |
| `stats.py` | Summary statistics and error helpers. |
| `types.py` | Shared dataclasses. |
